# Supermarket Sales Analytics Dashboard 📊

## 📌 Project Overview
An end-to-end Power BI analytics project designed to analyze supermarket sales performance, evaluate customer demographics, and identify high-revenue product lines across three major branches (Mandalay, Naypyitaw, and Yangon).

---

## 📈 Key Metrics & Insights
* **Total Sales Revenue:** $322.97K
* **Total Gross Income:** $15.38K
* **Total Units Sold:** 6,000 units across 1,000 transactions
* **Average Customer Rating:** 6.97 / 10
* **Customer Breakdown:** Member ($164K / 50.8%) vs Normal ($159K / 49.2%)
* **Gender Split:** Female ($167.8K / 51.98%) vs Male ($155.1K / 48.02%)
* **Payment Preferences:** E-Wallet (34.5%), Cash (34.4%), Credit Card (31.1%)

---

## 🛠️ Tools & Technologies
* **BI Tool:** Microsoft Power BI
* **Data Prep & Transformation:** Power Query
* **Analytics & Data Modeling:** DAX Measures & Dynamic Slicers
* **Source Data:** Excel Dataset
